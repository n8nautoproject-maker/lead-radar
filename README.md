# Lead Radar: поиск заявок в Telegram-чатах с ИИ-фильтром

Сервис читает отслеживаемые чаты, отбирает сообщения, в которых человек ищет исполнителя,
и присылает их в Telegram-группу и Google-таблицу.

## Как устроено

```
чаты Telegram ─> правила (keywords.json) ─> языковая модель (GigaChat) ─> группа в Telegram + Google-таблица
        ▲
        └─ автопоиск новых чатов с пробным периодом, поиск по тексту сообщений
```

- **Два уровня отбора.** Дешёвые правила отсекают большую часть потока, модель вызывается только для кандидатов.
- **Три потока:** заявки, проблемы людей, которые можно автоматизировать, вакансии.
- **Автопоиск чатов:** новые чаты читаются неделю и остаются, только если дали пользу.
- **Надёжность:** оповещения о сбоях в группу, ночные копии базы, systemd с автоперезапуском.

Стек: Python, Telethon, SQLite, GigaChat API, Google Apps Script, Linux.

## Запуск

1. `pip install -r deploy/requirements.txt`
2. Скопировать `.env.example` в `.env` и `keywords.example.json` в `keywords.json`, заполнить.
3. Для GigaChat положить корневой сертификат Минцифры в `certs/root.pem`.
4. `python tg.py login`, затем `python tg.py notify-setup` и `python tg.py watch`.
5. Для таблицы: `deploy/apps_script_sheet.gs` (инструкция внутри файла).
6. Для сервера: `deploy/setup.sh`.

## Замечания

- Это обезличенная копия рабочего проекта: словари и промпты здесь примеры, их нужно настроить под свою нишу.
- Используйте отдельный аккаунт Telegram и соблюдайте правила платформы: проект читает публичные чаты и не делает массовых рассылок.
- Файл сессии `*.session` даёт доступ к аккаунту. Не передавайте его и не коммитьте.
